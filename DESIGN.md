# ETG Acquisition Control Tower

## Direction

The CRM is an operating surface for API partner acquisition. The interface uses the discipline of a route control board. Every opportunity has a current stop, an owner, a next transfer, and a visible exception state.

## Color

- ETG violet `#7C3AED` is the brand accent.
- Deep violet `#171124` anchors navigation.
- Blue marks research and information.
- Amber marks approval and review.
- Teal marks successful conversion.
- Red remains reserved for blocked or destructive states.

## Typography

Use the existing Geist interface system. Use tabular numerals for metrics, values, and conversion rates. Keep labels direct and operational.

## Layout

Dense operational pages use hairline-separated panels and shared dashboard primitives. The acquisition funnel reads left to right on wide screens and top to bottom on narrow screens. Each stage exposes volume, conversion, and the next required action.

## Signature

The conversion board is the signature element. It behaves like a route line from discovered accounts to closed partners. Approval and manager handoff are explicit interchange points.

## Motion

Use the existing view transitions. Funnel segments change emphasis on focus and hover. Reduced-motion users receive immediate state changes.
