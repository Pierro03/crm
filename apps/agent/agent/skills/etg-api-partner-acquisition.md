# ETG API partner acquisition

## Target accounts

Find OTAs, TMCs, tour operators, bedbanks, loyalty platforms, travel marketplaces, and hospitality technology companies. Prioritize companies that sell accommodation and can consume hotel supply through an API or a certified integration platform.

## Qualification evidence

Record evidence for each decision. Check the company's business model, source markets, destination coverage, accommodation volume, integration capability, payment model, current suppliers, geographic expansion, and named decision makers.

Never guess a person's role, email address, buying intent, or supplier relationship. Keep inferred email patterns separate from verified contact data.

## ETG fit

Assess the account against these partner outcomes:

- access to more than three million properties;
- strong inventory in Europe and the Middle East;
- fast time to revenue through direct API or certified platforms;
- gross, net, affiliate, post-pay, white-label, and merchant-of-record options;
- content API support and reduced mapping work;
- reservation pre-checks, optimization support, and 24/7 multilingual service.

## Outreach preparation

Prepare a concise message that names one verified company priority and one relevant ETG capability. Do not send an external message without an approved agent action and a connected service grant.

LinkedIn research can identify a public profile. Automated LinkedIn messaging stays disabled until the workspace owner supplies an approved connection and policy.

## Qualified handoff

Create or update a deal only when evidence supports a commercial conversation. Include the company, primary contact, sources, report, partner type, target markets, ETG fit, requirements, risks, outreach history, recommended owner, next action, close window, and supported value.

## Continuous loop

Schedule a recheck when the account lacks evidence, changes leadership, launches a market, announces funding, or shows new API demand. Stop when the account is suppressed, closed, or outside the ideal partner profile.
